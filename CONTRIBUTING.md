# Contributing to Express Lens

Thank you for considering contributing to `@codebygarv/express-lens`! We welcome bug fixes, documentation improvements, and feature contributions.

---

## 🛠️ Development Setup

1. **Fork and clone the repository**:
   ```bash
   git clone https://github.com/codebygarv/ExpressMonitor.git
   cd ExpressMonitor
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run tests**:
   ```bash
   npm test
   ```

4. **Build distribution files**:
   ```bash
   npm run build
   ```

---

## 📋 Guidelines

- Keep the package zero external runtime dependencies.
- Ensure all public functions have corresponding unit tests in `test/`.
- Ensure TypeScript type declarations in `index.d.ts` match any JS changes.
- Follow Conventional Commits format for commit messages (`feat: ...`, `fix: ...`, `docs: ...`, `chore: ...`).
